# 每日速读 App · 设计文档

日期：2026-10-14
状态：已实现（2026-10-14 上线，首次试跑通过）

## 1. 意图

用户原来的定时任务"全球新闻日报"每天把一篇长 Markdown 发到 Gmail。问题：

1. 全是文字，太长，没有终点，没有可视化，没有交互。
2. Gmail 不方便。
3. 政治内容太多；用户更关心**商业、科技、娱乐**，尤其是**中国**的。

用户是硅谷的机器学习研究员，**在通勤路上用手机刷**。想要：可视化、简洁但信息密度高、现代的交互风格（用户提供了参考图：“清透质感 UI”）。

## 2. 目标 / 非目标 / 反目标

**目标**
- 每天早上自动更新一个手机网页 app，3–5 分钟读完，有明确的"读完了"终点。
- 内容：商业 / 科技 / 娱乐为主；中国 : 海外 ≈ 7 : 3。
- 每条新闻一张卡片，左右滑动阅读，带数字和小图表。
- 保留原任务的事实核查纪律（24 小时窗口、第一方来源、未证实不收录）。
- 可"添加到主屏幕"，像 app 一样打开。

**非目标**
- 原生 iOS/Android app、上架应用商店、原生推送。
- 多用户、账号、评论、分享给他人。
- 实时行情（数据每天只更新一次）。

**反目标（做到了也算失败）**
- 又变成一长串文字，滚不到底。
- 为了凑 7:3 或凑条数而放进低质量、未核实或旧闻。
- 政治新闻占比高（只有直接影响商业/科技/市场的政策才收录，并以"对生意的影响"角度写）。
- 编造数字、编造图表数据。图表上每个点都必须有来源。
- 视觉上像普通新闻列表或通用 AI 模板。

## 3. 已确定的做法（用户决定 / 已同意）

- **载体**：claude.ai 私密 Artifact 网页，链接固定：https://claude.ai/artifact/BVXAJfsgjVPQaf4TbfDaYZ 。用户在 Safari 中"添加到主屏幕"。该 Artifact 归用户所有，目前只放着旧原型、`data/index.json` 为空，没有真实数据：直接原地更新，URL 不变。（选择方是 Claude，用户可推翻；备选是 GitHub Pages，但会公开。）
- **视觉风格：清透质感**（用户参考图见 `docs/design-reference/clear-ui-*.png`，实现时必须先看图）
  - 极浅灰白底，边缘带淡紫/淡蓝柔光晕。
  - 大圆角白色半透明卡片，靠柔和阴影 + 细高光浮起；不用重毛玻璃、不用粗边框。
  - 大号数字作主角，单位小一号跟随。
  - 图表：细线 + 极淡渐变填充 + 当前值气泡 + 底部刻度。
  - 每屏只有一个高饱和"光点"强调色（带同色光晕），其余黑白灰。
  - 底部胶囊形 tab bar，中间一个突出主按钮。
  - 大量留白，一张卡片只讲一件事。
- **阅读方式**：新闻卡片左右滑动；顶部进度点；滑到最后是"今天读完了"页。
- **首页**：问候 + 日期；一张大数字卡（含小走势线）；中国/海外 + 分类比例的小图；"开始今天的速读"主按钮。
- **提醒**：定时任务结束时由 Claude App 推送通知（含今日标题 + 链接）。不再发 Gmail。
- **UI/UX 技能**：实现时加载并使用 `frontend-design`、`dataviz`、`design:design-system`、`design:ux-copy`、`design:accessibility-review`，完成后用 `design:design-critique` 自审一轮。

## 4. 结构

```
site/
  index.html            # 整个 app（单文件，HTML+CSS+JS，无构建步骤）
  data/index.json       # 往期列表 {"issues":[{"date":"YYYY-MM-DD","count":N,"headline":"..."}]}
  data/YYYY-MM-DD.json  # 每期内容
routine/
  prompt.md             # 定时任务完整提示词（与线上 Routine 保持一致）
docs/superpowers/specs/ # 本文档
```

页面只读数据文件；每天的任务只写 `data/*.json`，不改 `index.html`。`index.html` 改版由人发起，在本仓库修改后发布。

### 4.1 页面（三个 tab）

1. **今天**（默认）：问候、日期与覆盖窗口；主数字卡；比例图；"三句话看完今天"；主按钮进入滑动阅读。
2. **速读**：全屏卡片轮播。每张卡：地区标签（中国/海外）、分类、标题、一句话钩子、主数字（可选）、小图（可选）、2–3 个要点、"跟你有什么关系"、可信度 + 来源链接。左右滑 / 点按两侧切换；进度点；最后一页"今天读完了" + 接下来 72 小时日程。
3. **往期**：日期列表，点开任意一期进入同样的阅读。

已读进度、上次 tab 存在 localStorage（失败时页面照常可用）。

### 4.2 每期数据格式（`data/YYYY-MM-DD.json`）

```json

  "date": "2026-10-14",
  "window_pt": "10-13 06:50 → 10-14 06:50 PT",
  "cutoff_pt": "2026-10-14 06:40 PT",
  "tldr": ["≤30字", "≤30字", "≤30字"],
  "takeaway": "今天最值得记住的一句话，≤40字",
  "hero": {"label": "指标名", "value": "数值", "unit": "单位", "change": "+1.2%", "dir": "up|down|flat",
           "series": [{"x": "10-08", "y": 25800}], "source": {"name": "", "url": ""}},
  "markets": [{"label": "恒生指数", "value": "26,100", "change": "+1.2%", "dir": "up", "source_url": ""}],
  "stories": [{
    "id": "s1",
    "region": "cn|global",
    "category": "business|tech|ent",
    "importance": "high|medium",
    "credibility": "confirmed|credible|developing",

    "hook": "≤40字",
    "headline_number": {"value": "+38%", "label": "同比"},
    "chart": {"type": "line|bar", "unit": "", "points": [{"x": "", "y": 0}], "source_url": ""},
```

## 5. 定时任务（Routine）

- 新建 Routine，每天 **05:20 America/Los_Angeles**（旧任务实测约 90 分钟，保证 7 点前后可读），每次新开会话，只开推送通知。
- 旧 Routine `trig_01XeM4XfCyypo8x2pYVb2ja4`（已被用户停用）保持停用，不删除。
- 核查规则来源：旧 Routine 的完整提示词（可用 `get_trigger trig_01XeM4XfCyypo8x2pYVb2ja4` 读取）。保留其“时间纪律”、阶段二全部核查项、可信度分级与 APPROVE/HOLD/REJECT 准入规则；去掉其长文格式规范和 Gmail 投递。
- 流程：发现 → 核查 → 编辑成 JSON → 自审 → 发布到固定 Artifact → 推送摘要。保留原任务的时间纪律与核查规则，去掉长文模板。
- 选题配额：最多 10 条（少于 10 条可以）；目标中国 7 / 海外 3，合格新闻不足时宁缺毋滥，比例偏离要在运行摘要中说明。分类以商业、科技、娱乐为主；"中国"包括大陆、港澳台企业与市场，以及海外事件对中国企业的直接影响。
- 发布：读取 Artifact 现有 `data/index.json`，写入当天 JSON，更新索引（保留最近 60 期），以固定 URL 更新 Artifact，仅上传 `data/` 文件。
- 失败兜底：发布失败重试一次；仍失败时把当天 JSON 原文输出在会话里，并在推送摘要里写明失败。

## 6. 留给实现者决定

- 地区标签（中国/海外）用中性灰色胶囊区分，不占用强调色（Claude 的决定）。涨跌除颜色外必须带 ▲▼ 符号。
- 涨跌配色按美股习惯：绿涨红跌（用户决定）。
- 字体、具体色值、动效细节（遵循第 3 节风格与可访问性要求，深色模式也要好看）。
- 小图表的具体绘制方式（手写 SVG 即可，不强制图表库）。
- 主数字卡每天选哪个指标：优先当天头条新闻相关的已核实数字；否则选一个与中国商业/科技相关的市场指标（如恒生科技指数近 5 个交易日）。
- 首次发布后用一期真实数据端到端试跑一次（手动触发 Routine）。
